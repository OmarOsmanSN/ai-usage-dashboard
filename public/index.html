How is the estimated cost calculated?

For each model, ccusage multiplies each token type by that model's price per token and adds them up:

cost = input × input price + output × output price + cache write × cache-write price + cache read × cache-read price

Prices come from the public LiteLLM model price list (the same list per-token API prices are published in).

  • Prices: built-in list – a copy shipped inside ccusage 20.0.26. Works offline, but models released after that version show as Unpriced.
  • Prices: latest online – ccusage downloads the current list on each run, so new models get a price.

This is what the same usage would cost on the pay-as-you-go API. On a Pro/Max subscription you pay a flat fee, so it is not your bill.
